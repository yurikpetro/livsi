# LIVSI — документация проекта

Проект интернет-магазина косметики LIVSI. На момент создания документов ТЗ отсутствует, на входе только макет главной страницы и брендбук.

| Документ | Содержание | Для кого |
|---|---|---|
| [01-audit.md](01-audit.md) | Аудит макета и брендбука: что есть, чего нет, технические замечания, извлечённые из брендбука требования, палитра и типографика | разработка, дизайн |
| [02-plan.md](02-plan.md) | Стек и обоснование, архитектура, модель данных, дизайн-токены, объём работ по этапам, оценка в часах, риски | разработка, менеджмент |
| [03-payments-and-delivery.md](03-payments-and-delivery.md) | Варианты приёма оплаты (СБП и альтернативы) с плюсами и минусами, доставка Ozon и альтернативы, чеклисты интеграций, юридический блок | заказчик, разработка |
| [04-questions-for-client.md](04-questions-for-client.md) | Опросник для составления ТЗ, 12 блоков, с приоритетами 🔴🟡⚪️ и чеклистом доступов | **отправить заказчику** |
| [05-platform-choice.md](05-platform-choice.md) | Ответ на вопрос «на чём делать»: Тильда vs готовая платформа vs своё решение; сравнение стоимости владения за 3 года; два сценария объёма (А/Б) | **отправить заказчику** |
| [06-scope-v2.md](06-scope-v2.md) | **Актуальный объём работ.** Зафиксированные решения по всем ответам заказчика, противоречия и блокеры, архитектурные решения, пересчёт оценки с разбивкой на Релиз 1 / Релиз 2, требования к новому макету Figma | разработка + заказчик |
| [07-design-review.md](07-design-review.md) | Ревью Figma-файла и живого прототипа: вердикт по готовности к старту, что закрыто и что отсутствует, расхождения с договорённостями, список задач дизайнеру | разработка + дизайнер |
| **[08-roadmap.md](08-roadmap.md)** | **Трекер прогресса.** Что сделано, что осталось, чем заблокировано, что берём следующим. Чеклист по всем блокам, технический долг, порядок работ | ежедневная работа |

> Приоритет документов при расхождениях: **08** → **07** → **06** → 02 → 01.
> Текущее состояние работ всегда в [08-roadmap.md](08-roadmap.md) — начинать день лучше с него.

## Порядок действий

Опросник закрыт, ТЗ зафиксировано, каркас и витрина собраны. Текущие шаги и приоритеты — в [08-roadmap.md](08-roadmap.md), разделы 2 (блокеры) и 7 (порядок работ).

## Исходные материалы
