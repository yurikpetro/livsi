# LIVSI — интернет-магазин

Косметика для дома и профессионалов. Домен — `livsi.shop`.

Документация проекта — в [`docs/`](docs/README.md). Актуальный объём работ и решения:
[`docs/06-scope-v2.md`](docs/06-scope-v2.md), ревью макетов — [`docs/07-design-review.md`](docs/07-design-review.md).

## Стек

PHP 8.3 · Laravel 13 · PostgreSQL (локально SQLite) · Redis · Tailwind CSS 4 · Vite · Filament (админка, следующий инкремент)

## Запуск

```bash
composer install
npm install
cp .env.example .env
php artisan key:generate
php artisan migrate --seed
npm run build
php artisan serve
```

Открыть http://localhost:8000

Для разработки с горячей перезагрузкой — `npm run dev` во втором терминале.

## База данных

По умолчанию локально используется **SQLite** (`database/database.sqlite`): в текущей сборке PHP
не подключено расширение `pdo_pgsql`, а демон Docker не запущен. Целевая СУБД — PostgreSQL 16,
миграции написаны переносимо.

Чтобы перейти на PostgreSQL:

1. Раскомментировать `extension=pdo_pgsql` в `php.ini` (DLL уже лежит в каталоге `ext`).
2. Поднять сервисы: `docker compose up -d`
3. В `.env` указать `DB_CONNECTION=pgsql` и параметры подключения.
4. `php artisan migrate:fresh --seed`

## Важные соглашения

- **Деньги — целые копейки** (`integer`), никаких `float`. Форматирование — `App\Support\Money`.
- **Остатки** ведутся квотой сайта (`stock_quotas`), а не синхронизацией с учётной системой:
  маркетплейсы торгуют из своей части склада. См. `docs/06-scope-v2.md`, § 2.1.
- **Рейтинги и отзывы** вводятся вручную и всегда показываются с указанием площадки-источника.
  См. `docs/07-design-review.md`, § 8.1.
- **Пороги промо** (бесплатная доставка, подарок) живут в настройках, а не в `.env`.
- **Ставка НДС** — поле товара со значением по умолчанию из настроек, не константа.
- Шрифт **Geist** в публичном дистрибутиве идёт **без кириллицы** — она закрыта Inter,
  пока дизайнер не пришлёт расширенную версию.
