# LIVSI — интернет-магазин

Косметика для дома и профессионалов. Домен — `livsi.shop`.

Документация проекта — в [`docs/`](docs/README.md).
**Текущее состояние работ — [`docs/08-roadmap.md`](docs/08-roadmap.md).**

## Стек

PHP 8.3 · Laravel 13 · PostgreSQL (локально SQLite) · Redis · Tailwind CSS 4 · Vite · Livewire 3 · Filament 5 (админка)

## Запуск

```bash
composer install
npm install
cp .env.example .env
php artisan key:generate
php artisan migrate --seed
npm run build
php artisan serve
```

Открыть http://localhost:8000

Для разработки с горячей перезагрузкой — `npm run dev` во втором терминале.

Письма по заказу ставятся в очередь (`QUEUE_CONNECTION=database`), поэтому
для их отправки нужен работник — иначе они просто копятся в таблице `jobs`:

```
php artisan queue:work
```

Локально `MAIL_MAILER=log`, и письмо приходит в `storage/logs/laravel.log`.

## База данных

По умолчанию локально используется **SQLite** (`database/database.sqlite`): в текущей сборке PHP
не подключено расширение `pdo_pgsql`, а демон Docker не запущен. Целевая СУБД — PostgreSQL 16,
миграции написаны переносимо.

Чтобы перейти на PostgreSQL:

1. Раскомментировать `extension=pdo_pgsql` в `php.ini` (DLL уже лежит в каталоге `ext`).
2. Поднять сервисы: `docker compose up -d`
3. В `.env` указать `DB_CONNECTION=pgsql` и параметры подключения.
4. `php artisan migrate:fresh --seed`

## Админка

Адрес `/admin`. Доступ только у пользователей с флагом `is_admin` — покупатели будут
жить в той же таблице `users`, поэтому проверка обязательна.

Администратор создаётся сидером, руками ничего заводить не нужно:

```bash
php artisan db:seed --class=AdminUserSeeder
```

На локальной машине это `admin@livsi.shop` / `livsi-admin` — значения по умолчанию
из `config/livsi.php`. Сидер идемпотентен: повторный запуск обновляет пароль
существующего администратора, а не плодит копии.

На боевом контуре данные задаются в окружении. Без них администратор
не создаётся вообще, чтобы общеизвестный пароль не уехал в продакшен:

```
ADMIN_EMAIL=you@example.com
ADMIN_PASSWORD=...
```

## Важные соглашения

- **Деньги — целые копейки** (`integer`), никаких `float`. Форматирование — `App\Support\Money`.
- **Остатки** ведутся квотой сайта (`stock_quotas`), а не синхронизацией с учётной системой:
  маркетплейсы торгуют из своей части склада. См. `docs/06-scope-v2.md`, § 2.1.
- **Рейтинги и отзывы** вводятся вручную и всегда показываются с указанием площадки-источника.
  См. `docs/07-design-review.md`, § 8.1.
- **Пороги промо** (бесплатная доставка, подарок) живут в настройках, а не в `.env`.
- **Ставка НДС** — поле товара со значением по умолчанию из настроек, не константа.
- Шрифт **Geist** в публичном дистрибутиве идёт **без кириллицы** — она закрыта Inter,
  пока дизайнер не пришлёт расширенную версию.
